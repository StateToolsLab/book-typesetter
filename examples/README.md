# ビフォーアフターのサンプル

`before-after.png` は、架空の文章（下）を A5 縦組で 2 回組んだものです。右が適用前、左が適用後です。赤い番号は、下の表の番号と同じです。

本文 9.8pt、行送り 19pt、1 行 44 字、1 頁 16 行。組版ソフトは DesignCraft です。スキルの手順に沿って人が技を当てたもので、スキルの実行結果をそのまま載せたものではありません。

## 測った数字（PDF の文字の層）

| # | 何を | 適用前 | 適用後 |
|---|---|---|---|
| 1 | 俳句の前後のあき | 0pt | 19pt（1 行）ずつ |
| 2 | 段落「店の棚に…」の行数 | 3 行（最後は「る。」の 2 字） | 2 行 |
| 2 | 詰めた約物（段落の 1 行目の「、」「。」） | 9.8pt | 4.9pt |
| 3 | 「〔」の箱の上端 | 131.0pt | 125.6pt |
| 4 | 番号の頭の上端／折り返しの上端 | 140.8pt／131.0pt | 131.0pt／131.0pt |

適用前の詰まない行は、字の送りが 10.03pt に広がっていました。適用後は 9.8pt です。

## 2 の計算
「。」は行の頭に置けないので、「る」も一緒に次の行へ送られ、「る。」の行ができます。前の行に 1 字分（9.8pt）の余地を作れば、字が順に前へ送られて、行が消えます。

```
足りない量 = 9.8pt
1 か所の削り = 9.8pt ÷ 2 か所 = 4.9pt（約物 1 字で削れる上限の半字）
```

## 本で使った例
実際の本では、45 字の行に「。」「、」「、」の 3 か所があり、1 か所 3.27pt ずつ（9.8pt → 6.53pt）詰めて収めました。削る量は、行の中の約物の数で決まります。

> 〔町の便り〕
>
> 製本所の主人によれば、よい本は開くと頁が自然に落ち着くという。
>
> ①頁の順は、綴じる前に必ず指で確かめて、背を固める前にもう一度見直すことが大切である
>
> ②糸は締めすぎず、開いたときに頁が自然に落ち着く強さで、ひと針ずつ止めることが肝心である
