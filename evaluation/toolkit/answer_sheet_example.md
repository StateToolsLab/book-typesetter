# 答えの紙の例（依頼者の役。実行役には見せない）

架空の本の例です。手元の本に合わせて書き直してください。文字の大きさや行間の数字は、依頼者は知らないものとします。

- 何を作るか: 町の料理教室の講座のテキスト。紙と電子書籍。
- 用途: 講座で使う。読みながら書き込みたい。
- 形式: 頁の形が保たれるもの。
- サイズ: A5。
- 組み方向: 横組、1 段。
- 余白: 外側を広めに取りたい。書き込めるスペースがほしい。
- 文字: 年配の人も読むので、詰めすぎない。数字は分からない。
- 図: 写真を入れる。頁の幅いっぱいでなくてよい。
- 頁の切れ目: 1 つの料理が 2 頁に分かれないようにしたい。
