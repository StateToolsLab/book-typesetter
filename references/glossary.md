# Glossary / 用語集

Terms used in this skill, for readers who work in English. Romanized terms are the ones used in Japanese typesetting. English terms follow W3C's [Requirements for Japanese Text Layout (JLReq)](https://www.w3.org/TR/jlreq/) where there is a matching term.

When answering in English, use the English term and give the Japanese term once in parentheses, so that the reader can talk to a Japanese printer or editor.

| 日本語 | Reading | English | Meaning here |
|---|---|---|---|
| 組版 | kumihan | typesetting | Arranging text and images on the page |
| 版面 | hanmen | type area | The area of the page that holds the text |
| 縦組 | tategumi | vertical writing | Lines run top to bottom; lines advance right to left |
| 字 | ji | character / em | One full-width character; used as a unit of length |
| 全角・半角 | zenkaku, hankaku | full-width, half-width | One em wide, half an em wide |
| 行送り | gyō-okuri | line feed (line pitch) | Distance from one line to the next |
| 格子 | kōshi | line grid | Fixed line positions that body text sits on |
| 行取り | gyō-dori | line-span placement | Giving a heading a whole number of lines, so that body text stays on the grid |
| 天・地 | ten, chi | head, foot | The top and the bottom of the type area |
| のど | nodo | gutter | The inner margin at the binding |
| 字下げ | jisage | indent | Vertical text is indented from the head |
| 柱 | hashira | running head | The chapter title in the margin |
| ノンブル | nonburu | folio, page number | From the French *nombre* |
| 見出し | midashi | heading | 柱見出し is a large section heading, 中見出し a smaller one |
| 短い末行 | — | short last line, runt | The last line of a paragraph with only a few characters. 頁の頭に来ると特に目立つ |
| 折り返し | orikaeshi | continuation line | The second and later lines of a paragraph or list item |
| 泣き別れ | nakiwakare | stranded heading | A heading left at the end of a page, apart from its text |
| 込め物 | komemono | spacing material, quads | Metal blanks placed between characters in metal type |
| 約物 | yakumono | punctuation marks | 、。「」（）〔〕 and similar |
| 禁則 | kinsoku | line-breaking rules | For example, 。 may not start a line |
| 追い込み | oikomi | pushing in | Tightening punctuation to pull a character back into the previous line |
| 追い出し | oidashi | pushing out | Widening a line to push a character on to the next line |
| ぶら下げ | burasage | hanging punctuation | Letting punctuation stick out past the type area |
| 縦中横 | tatechūyoko | tate-chu-yoko | Upright horizontal digits inside a vertical line |
| ルビ | rubi | ruby | Small reading aids beside the characters |
| 原本 | genpon | the source | The original printed book being reset |
| 正本 | seihon | master text | The corrected text that the layout is built from |
| 校閲 | kōetsu | proofreading | Checking by a separate person or agent |
