# 約物の決まり（本ごとの JSON）

句読点やかっこを全角で組むか半角で組むかは、本ごとに決めます。決めた基本だけを、本のフォルダの `約物の決まり.json` に残します。詰めるときの例外は、この基本を変えずに、上に段落ごとに足します。

## なぜ分けるか
- 基本と例外が混ざると、どこまでが本の決まりで、どこからが 1 段落のための詰めかが分からなくなる。
- 組み直すたびに設定を読み解かなくても、次の組みを同じ基本から始められる。
- 基本を変えたときに、見直す例外が分かる。

## 決め方
- 組む前の聞き取り（`intake.md`）で聞く。好みが無い、分からないと言われたら、JIS の組み（JLReq）のふつうの形をおすすめにする: 約物は全角、約物が続く所は前の約物を半角。
- 原本や見本があれば、そこから読んで「見本から読んだ値」として見せる。原本どおりにするかは目的で決める（原本が半角でも、全角のほうが読みやすいと判断された例がある）。
- 文字の大きさや行送りと同じく、組んだ頁を見てから決め直してよい。決め直したら、日付と決めた人を書き換える。
- 字の種類ごとに決める。1 つの本で、句読点は全角、丸かっこは半角、のように分かれてよい。

## 考えること
ユーザーに教わった判断です（2026-11-11）。どの本にも当てはまるとは限らないので、おすすめの理由として使います。

| 字 | 全角にすると | 半角にすると |
|---|---|---|
| 句読点「、。」・中黒「・」 | 後ろに空きが残り、詰めるときの余白になる | 頁に入る字は増えるが、詰める余地が減る |
| 丸かっこ「（）」 | 注釈のように挟む語の前後があいて、間延びして見えることがある | 挟んだ語が本文に寄り、読む流れが切れにくい |
| かぎかっこ「「」」『』」 | ゆったり見える。段落の 1 字目では、下げと合わせて間があきすぎて見えることがある | 原本が半角でも、詰まって見えることがある |

- 段落の 1 字目のかぎかっこだけを半角にする、のような例外も基本に書く。頁をまたいだ続き（前の頁から続く段落の、頁の頭）には当てない。
- 決めていない字（〝〟〔〕〈〉《》【】など）は「未定」と書き、出てきたときに聞く。

## 詰めるときの順
1 か所を直すための詰めは、基本の上に足す例外です。軽い順に決めておくと、毎回迷いません（技の全体は `techniques.md` の「追い込み」）。

例:
1. 読点「、」の後ろを 1/3 字詰める（その段落だけ）
2. それでも足りないときだけ、その段落の字間を詰める（3% まで、など上限を決める）

- 例外は段落ごとに、組みの設定と、その版の一覧（`組み直しN_推奨と原本から変えた所_日付.md`）に書く。JSON の「詰めるときの順」は順番だけで、どの段落に当てたかはここに書かない。
- **基本を変えたら、例外を見直す。** 行の切れ目が章の終わりまで動くので、前の詰めが要らなくなったり、逆に段落の最後に「る。」のような短い行を作ったりする。組み直して、例外を 1 つずつ外すか残すかを頁で確かめる。
- ユーザーが確定した頁を前の基本のまま残すときは、「例外の所」に頁とわけを書く。

## 雛形
本のフォルダに `約物の決まり.json` として写し、空の所を埋めます。値の「決め方」は、組みの仕様と同じ言葉（ユーザー／見本から読んだ／おすすめ／仮に決めた／未定）を使います。

```json
{
  "_説明": "この本の約物の幅の基本。詰めるときの例外は、この基本の上に段落ごとに足す（組みの設定と、各版の一覧に書く）。",
  "本": "",
  "決めた日": "",
  "決めた人": "",
  "基本": {
    "句読点": {"字": "、。，．", "幅": "全角", "決め方": "", "わけ": ""},
    "中黒": {"字": "・", "幅": "全角", "決め方": "", "わけ": ""},
    "丸かっこ": {"字": "（）", "幅": "全角", "決め方": "", "わけ": ""},
    "かぎかっこ": {"字": "「」『』", "幅": "全角", "決め方": "", "わけ": "",
      "例外": {}},
    "約物が続く所": {"幅": "前の約物を半角", "決め方": "おすすめ", "わけ": "JIS（JLReq）のふつうの組み"},
    "ほかの約物": {"字": "〝〟〔〕〈〉《》【】", "幅": "未定（出てきたら聞く）"}
  },
  "詰めるときの順": [],
  "例外の所": {},
  "組みの設定での書き方": {}
}
```

- 「幅」は「全角」「半角」「未定」のどれか。例外は「例外」に、どの所で何にするかを言葉で書く（例: `"段落の 1 字目の「『": "半角。頁をまたいだ続きの頭には当てない"`）。
- 「例外の所」は、前の基本のまま残した頁や段落。本の事情なので、わけも書く。
- 「組みの設定での書き方」は、下の写し方で作った値を、使った道具の設定の名前で書く。

## 組みの道具への写し方
基本は、道具の設定に機械的に写せる形にしておきます。

- **半角にする字を 1 本の正規表現にまとめる。** 3 つを `|` でつなぐ。
  - 基本で半角にした字（例: 丸かっこを半角にした本なら `[（）]`）
  - 後ろに約物が続く閉じの約物: `[、。，．」』）〕〉》】〟・](?=[、。，．」』）〕〉》】〟「『（〔〈《【〝・])`
  - 後ろに開きの約物が続く開きの約物: `[「『（〔〈《【〝](?=[「『（〔〈《【〝])`
- その正規表現に、約物を詰める文字スタイル（縦組は OpenType の `vpal`、横組は `palt`）を当てる。全角のまま残す字は、正規表現に入れない。
- 段落の 1 字目だけの例外は、`^[「『]` のような別の式を、段落の頭のスタイルにだけ当てる。頁をまたいだ続きのかけらには当てない。
- 道具が段落全体に効く設定しか持たないときは、例外を当てた段落の全部の行が動く。組んで画像で確かめる。
- DesignCraft での書き方は `tools-designcraft.md`。InDesign なら文字組みアキ量設定、Word なら文字体裁のオプションに当たるが、そちらで写した例はまだない。

## 組んだあと
- 半角・全角が決まりどおりかは、組んだ版の字の位置を測って確かめる（`measuring.md`）。
- 決まりと違う所が見つかったら、直すか「例外の所」に書くかをユーザーに聞く。
